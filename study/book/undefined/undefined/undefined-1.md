# 저장소와 검색

데이터의 근간은 요청을 받으면 데이터를 저장하고 그 데이터를 요청하면 다시 데이터를 제공한다.

특정 작업부하 우형에서 좋은 성능을 내기위해 저장소 엔진이 내부에서 수행되는 작업에 대해 대략적인 개념을 이해할 필요가 있다.

로그 구조와 와 같은 계열 저장소 엔진과 b tree 구조와 같은 페이지 지향 계열 저장소 엔진을 검토한다 .&#x20;

많은 데이터베이스는 내부적으로 추가(append-only) 전용 데이터 파일인 log 를 사용한다.&#x20;

애플리케이션 로그는 애플리케이션에서 무슨 일이 일어났는지 기술한 텍스트를 출력한다. 해당 책에서 로그는 좀 더 일반적인 의미로 연속된 추가 전용 레코드다 . 사람이 읽을수 있지 않아도 된다. 바이너리라도 된다.&#x20;

조회를 하는데 있어 색인을 씀으로서 읽기를 개선할수있지만, 쓰기에서 문제가 될수있다.&#x20;
